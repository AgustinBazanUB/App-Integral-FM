# Manual breve para vendedores

1. Ingresá en `/gestion` con tu email y contraseña.
2. Abrí “Venta rápida” o “Ubicaciones”; sólo aparecen tus ubicaciones autorizadas.
3. Elegí la ubicación de salida.
4. Sumá productos con `+`; el control no permite superar el stock visible.
5. Elegí canal, forma de pago, retiro/envío y DNI cuando corresponda.
6. Confirmá una sola vez y esperá el código de venta.

La confirmación descuenta stock y registra movimientos en una transacción. Si falta stock o internet, la operación se revierte. No vuelvas a cargar una venta sin comprobar antes si apareció el código.

Sin conexión se puede consultar contenido ya cacheado, pero no se deben confirmar ventas. Para anular o editar una operación, usá el permiso asignado o solicitá ayuda al encargado.
