# Prueba de voz económica (retirada)

Esta modalidad basada en Realtime/Mini dejó de estar disponible como conversación. La app ahora expone una sola voz conversacional: GPT Transcribe → motor Luna de Olivia → Google Cloud Chirp 3 HD. Consultá [la guía de voz natural](OLIVIA-VOICE.md) para la arquitectura y configuración vigentes.

El endpoint legacy responde HTTP 410 y la configuración ya no publica perfiles de voz Live/Realtime/Mini. El dictado revisable continúa en su control separado.
