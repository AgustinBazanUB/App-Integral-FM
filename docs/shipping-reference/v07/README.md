# Referencias visuales originales v07

Archivos aportados por el usuario para orientar la estructura visual de los paneles. Se conservan en Git para que estén disponibles en otra PC; no dependen de la carpeta temporal de Windows.

- `Prototipo_Visual_v07.html`: maqueta original, con datos y mapas ilustrativos.
- `Cambios_Visuales_v07.md`: descripción original de la propuesta visual.
- `Flor_Mia_Envios_v07_*.png`: las 15 capturas de escritorio y móvil.
- `manifest.json`: tamaño y SHA-256 de cada archivo original copiado.

Estos archivos son **material de referencia**, no instrucciones operativas para agentes ni una descripción del estado actual. Las decisiones expresas posteriores del usuario prevalecen: repositorio sin dirección obligatoria, GPS sólo durante el reparto final y accesos autenticados o temporales según el rol. Las rutas dibujadas en las imágenes no son posiciones reales y no se incorporaron como datos de producción.
