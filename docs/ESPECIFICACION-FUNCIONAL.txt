<objetivo-general>
Construir una aplicación web integral para administrar Flor Mía desde una única plataforma.

La aplicación debe reunir 12 módulos de negocio dentro de un mismo sistema:

1. Ubicaciones.
2. Ventas rápidas.
3. Clientes fidelizados.
4. Métricas generales.
5. Administración financiera.
6. Depósito.
7. Página web y ecommerce.
8. Redes sociales.
9. Marketing.
10. Gestión de envíos.
11. Alertas.
12. Gestión de proveedores.

Además, debe existir una capa transversal para:

* Autenticación.
* Administración general.
* Usuarios.
* Roles.
* Permisos.
* Auditoría.
* Notificaciones.
* Configuración.
* Datos compartidos entre módulos.

Cada persona debe ver únicamente los módulos, ubicaciones, datos y acciones que el administrador le haya autorizado.
</objetivo-general>

<contexto-del-negocio>
Flor Mía es un negocio que comercializa productos regionales mendocinos, principalmente:

* Aceite de oliva.
* Frutos secos.
* Pistachos.
* Almendras.
* Aceitunas.
* Mermeladas.
* Sales.
* Vinos.
* Otros productos regionales.

El negocio vende mediante diferentes canales:

* Locales físicos.
* Ferias.
* Eventos.
* WhatsApp.
* Instagram.
* Página web.
* Ventas directas o manuales.
* Futuras suscripciones o ventas recurrentes.

El sistema debe registrar y relacionar la mayor cantidad posible de operaciones del negocio, evitando datos duplicados y permitiendo analizar toda la información desde una sola aplicación.

Debe poder utilizarse desde Google Chrome en:

* Computadoras.
* Tablets.
* Celulares Android.
* iPhone.

La interfaz debe ser especialmente rápida y sencilla para vendedores que trabajan desde un celular o con una botonera Bluetooth.

### Estrategia de integración

2. Crear un repositorio nuevo para la plataforma integral o una rama de integración claramente separada.
3. Utilizar la web React/Vite como base tecnológica visual.
4. Migrar al nuevo sistema la lógica comprobada de stock, ubicaciones y ventas.
5. Extraer la comunicación con Firestore a una capa de servicios independiente de la interfaz.
6. Evitar duplicar usuarios, productos, ventas, stock o configuraciones.
7. Preparar una migración segura de los datos existentes.
8. Validar cada módulo antes de retirar los sistemas anteriores.

<instruccion-final>
Construye la plataforma integral de Flor Mía siguiendo este documento.

Antes de modificar código:

1. Inspecciona los dos repositorios.
2. Presenta la auditoría.
3. Define la estrategia de integración.
4. Identifica riesgos y decisiones pendientes.
5. Crea una rama o repositorio de integración.
6. Conserva intactas las versiones productivas.
7. Comienza por la base de autenticación, permisos y navegación.
8. Integra primero el módulo de Ubicaciones.
9. Avanza por etapas verificables.

No inventes datos comerciales, fiscales, precios, productos, credenciales, permisos ni integraciones.

Cuando falte información menor, utiliza una configuración editable o un estado “pendiente”.

Cuando falte información crítica para una integración externa, deja preparada la interfaz técnica, documenta lo necesario y continúa con el resto de la aplicación.

El resultado debe ser una aplicación real, segura, intuitiva, modular, responsive y preparada para convertirse en el sistema central del negocio.
</instruccion-final>
